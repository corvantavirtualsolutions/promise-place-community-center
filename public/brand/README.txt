Promise Place Community Center — logo files
===========================================

WHICH ONE DO I USE?

  promise-place-logo-horizontal.*      Default. Use this unless you have a
                                       reason not to. Letterhead, email
                                       signatures, documents, website headers.

  promise-place-logo-stacked.*         When the space is tall and narrow, or
                                       square-ish. Flyers, posters, signage.

  *-white.*                            On dark or coloured backgrounds ONLY.
                                       Never on white — you won't see it.

  *-black.*                            One colour. Faxes, photocopies, forms,
                                       embroidery, anything printed in a
                                       single ink.

  promise-place-mark-only.*            The roof on its own, no words. Only
                                       where the name already appears nearby.

  promise-place-social-avatar.png      Facebook / Instagram / Google profile
                                       picture. Square, 1024x1024.

SVG OR PNG?

  SVG  — sharp at any size, tiny file. Use for print, signage, and anywhere
         that accepts it. This is the better file.
  PNG  — for anything that won't take an SVG. Transparent background, so it
         drops onto any colour.

A FEW RULES

  - Don't stretch it. Hold Shift when resizing so the proportions stay.
  - Don't recolour it. Use the white or black version instead.
  - Leave clear space around it, about the height of the roof on every side.
  - Don't put the colour version on a dark or busy background. Use white.
  - Don't add effects — drop shadows, outlines, gradients over the top.

The text is already converted to outlines, so you do NOT need to install any
font. It will look identical on every computer.
